# G-Helper · ROG Claymore II 定制版

本分支保存已用于日常运行的龙骑士二代修复，基于上游 **v0.279**。这是个人定制源码，不是官方发行版。

- **源码分支：** `claymore-ii-v0.279`
- **核心修复提交：** `32d9b3c6dcaf54f45d9c4ba0856f30b490db4c24`，仅包含 7 个生产代码文件，方便以后 cherry-pick。
- **官方基线：** `5b0029057541bff4cbd025e1a01e0641e11bd64e`（v0.279）
- **下次升级先读：** [升级指南](docs/CLAYMORE-II-UPGRADE.md) 和 [交接说明](handoff.md)。

## 包含哪些更改

1. 识别 Claymore II 有线模式 `0B05:1934`，保留原无线模式 `0B05:196B`。
2. 将笔记本 Gradient 渐变和 Ambient 屏幕取色的四区颜色按外接键盘横向位置插值，不再压成单色。
3. 使用二代独立的 ANSI/ISO 主键区 LED 地址表，并在外设设置中增加“小键盘位置”。左侧安装时主键区地址整体增加 `0x20`。
4. 合并积压帧、使旧同步帧失效，并处理 USB 超时/错误响应，避免切换效果后旧帧覆盖新设置。
5. 保留其他键盘的单色回退和手动逐键控制。

空间映射范围是**主键区**；可拆卸数字键盘本身、Logo 和额外媒体灯不在此实现范围内。左右位置需手动选择，没有猜测未确认的设备状态字节。

## 构建与离线检查

需要 Windows、.NET 10 SDK（本次使用 10.0.400）。在仓库根目录运行：

```powershell
.\scripts\build-claymore.ps1 -RunChecks
```

产物位于 `artifacts/claymore/GHelper.exe`，不会自动安装、启动或修改自启动任务。脚本设置 `GITHUB_ACTIONS=true`，以禁用上游“构建时退出正在运行的 G-Helper”的目标。

20 项检查通过模拟 USB 调用生产类，配置和日志仅写入测试输出目录；不访问真实 HID、抓屏或启动 G-Helper。原验证连续通过 10 轮。用户已确认映射修正版可用于日常运行；这不等于无线、睡眠唤醒、热插拔及长期运行都经过系统验证。

## 更新与安装注意

当前定制版使用官方已有的 `skip_updates=1` 配置保护，防止官方更新覆盖补丁。**这项配置不是代码默认值，也没有新增自动合并/更新服务。** 新装或更换配置时，需要退出程序后再保留该项，且不要覆盖其他用户设置。

后续升级应先把本次修复合入目标上游版本，运行离线检查，再征得用户同意后替换主力程序。不要把仓库里的源码/构建成功理解成已获实机切换许可。
